Sqlkit: a program and a library

Sqlkit is a mini framework based on pygtk that provides some very powerfull classes to edit databases. As a usage example sqledit is a full-featured data editor. Sqlkit is based on:

  • Python
  • Pygtk
  • sqlalchemy (>=0.5)
  • puthon_dateutils
  • babel for localization
  • the correct driver for your database of choice
