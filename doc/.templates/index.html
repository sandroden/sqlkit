Sqlkit: a program and a library

Sqlkit is a library bsed on pygtk that provides some very powerfull classes to edit databases. As a usage example sqledit is a full-featured data editor. Sqlkit is based on:

  • Python
  • Pygtk
  • sqlalchemy (>=0.5)
  • dateutils
  • babel
  • the correct driver for your database of choice
