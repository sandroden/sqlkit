Sqlkit: a program and a library

Sqlkit is a library based on pygtk that supplies some very handy classes to edit databases, as a usage example supplies also ``sqledit`` an editor that uses these classes. Sqlkit is based on:

  • Python
  • Pygtk
  • sqlalchemy (>=0.5)
Main feaures are:
  • Table & mask (one record at a time) view
  • Easy filter widget to select records
  • Easy way to see foreign key values
  • Completion while editing on foreign key and on already used values
  • Works with postgresql, mysql and sqledit (but easily extendible to any database supported by sqlalchemy)
  • Can edit a join table
  • Allows very easy composition of layout for mask view
